🚀 Sobre o Projeto

O CMC (CollectionsMinecraft) é um projeto open-source focado em criar um minecraft totalmente do zero usando apenas o JDK padrão. Qualquer pessoa pode estudar, modificar e colaborar com o código!

⚡ Funcionalidades

  • Engine 3D Própria: Renderização matemática via Java Graphics2D.
  • Zero Dependências: Roda nativamente no Java sem instalar engines gigantes.
  • Sistema de Save: Leitura e escrita de mundos via arquivos JSON.
  • Construção Voxel: Colocação e destruição de blocos em tempo real.
